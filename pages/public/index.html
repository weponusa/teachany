📚 TeachAny Community Submit API

This is the community courseware submission endpoint for weponusa/teachany.

Endpoints

  • GET /health — Health check
  • POST /api/submit — Submit a courseware package

Usage

python3 scripts/submit-to-community.py <course-id>

Why Pages Functions?

This service was previously deployed on Cloudflare Workers (*.workers.dev), but due to SNI restrictions in mainland China, we migrated to Cloudflare Pages Functions (*.pages.dev) for accessibility.
