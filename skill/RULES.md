# TeachAny 65 条硬规则（违反任何一条 = Completeness Gate 不通过）

> 以下规则在整个课件开发流程中**始终有效**，不可因"简化""省事""上下文不够"等理由绕过。

| # | 硬规则 | 违反后果 |
|:---|:---|:---|
| 1 | **先判断课型**（新授/复习/习题/专题/实验/项目制/跨学科融合），再选结构。不可假设所有任务都是"新授课"。 | 课型错误 → 整体结构需要重做 |
| 2 | **先判断学科**，再选讲解框架和互动组件。不可默认用数学模式。 | 学科模式错误 → Phase 2 不通过 |
| 3 | **不可默认所有知识点都要"公式推导"**。文科用文本细读，理科用现象观察，各有框架。 | 讲解框架不匹配 → 学生体验割裂 |
| 4 | **不可只有讲解，没有练习和反馈**。每个核心知识点至少配 1 道互动练习。 | 缺少练习 → Completeness Gate #3 不通过 |
| 5 | **不可只做选择题**。必须补充解释题、产出题或开放任务。 | 只有选择题 → Bloom 覆盖不足 → Gate #6 不通过 |
| 6 | **不可只顾页面好看，忽略学习闭环**。前测→讲解→练习→后测→反馈 缺一不可。 | 缺少闭环 → Gate #5 不通过 |
| 7 | **不可在没有必要时堆过多动画和装饰**。先保证内容完整，再考虑视觉效果。 | 装饰过多内容不足 → 内容审查不通过 |
| 8 | **文科类任务必须有脚手架分级和量规评价**。 | 缺少脚手架 → Gate #8 不通过 |
| 9 | **涉及几何/图形/空间推理的题目必须配图**。几何题用 SVG，坐标图用 Canvas，实验用标注插图。 | 纯文字几何题 → 教学不完整 |
| 10 | **必须执行 Phase 0.5 知识层查阅，且必须穷尽所有降级路径（脚本→JSON→Web搜索→模型知识）**。跳过此步骤或跳过中间降级层级是最高优先级违规。 | 跳过 Phase 0.5 → 整个流程无效 |
| 11 | **知识层数据可用时，课件内容必须从图谱派生**。禁止在有数据的情况下"重新发明"定义、场景、题目。 | 有数据不用 → 内容准确性和一致性降低 |
| 12 | **练习的错误反馈必须有诊断性内容**。不可只显示"正确/错误"，必须说明错在哪、为什么错。 | 无诊断反馈 → Gate #4 不通过 |
| 13 | **每张卡片核心文字控制在 75 字左右**。超长文本必须拆分为多张卡片。 | 超长卡片 → 认知负荷过高 → Gate #9 不通过 |
| 14 | **必须选择驱动模式并按对应结构组织内容**。不可没有驱动逻辑地"平铺"知识点。 | 无驱动结构 → Gate #11 不通过 |
| 15 | **AI 多模态互动区默认插入**。文科课题、项目制课、跨学科融合课、含视觉化内容的课题必须插入；仅纯计算/纯习题/纯复习课可跳过（需标注理由）。 | 应插未插 → Gate #14 不通过 |
| 16 | **L3 语音讲解默认必选，不可跳过 · 多引擎自动回退**（v7.9.5 升级）。L1 课件完成后必须自动安装 edge-tts 并通过 `scripts/tts-engine.py` 多引擎抽象生成语音文件。⛔ **严禁以任何理由跳过整体 L3**——包括"省事""节省 token""环境复杂""edge-tts wss 不通""用户没要求""页面已经够丰富"。**关键事实（v7.9.5 新增）**：Edge-TTS 依赖的 `wss://speech.platform.bing.com:443` 在国内常被防火墙拦截，导致 edge-tts "成功"返回但写出 0 字节 mp3。**正确做法**：必须调用 `scripts/tts-engine.py`（自动按 edge-tts → 代理重试 → macOS say → pyttsx3 → 1 秒静音占位顺序回退），且每个 mp3 必须 ≥ 200 字节。preflight-check.py 会在 Phase 0 实测 wss 连通性，输出 `.teachany-preflight.json` 的 `capabilities.L3_tts_engine` 字段告知 AI 实际可用引擎。用户明确拒绝时仍须在 HTML 中保留 `teachany-tts-narrator.js` 引用（零 mp3 模式，前端用 Web Speech 朗读）。 | 无语音 / 直接调 edge-tts 不验证文件大小 / 因 wss 不通而跳 L3 → Gate 直接不通过 |
| 17 | **知识图谱未命中时必须执行 Web 搜索**。不可跳过 Web 搜索直接使用模型知识。搜索关键词需包含"课标""前置知识""易错点"等教学相关术语。 | 跳过搜索 → Phase 0.5 不通过 |
| 18 | **课件打包+注册+发布默认全部自动执行，不可跳过**（v7.9.4 强化）。L1 课件完成后必须按顺序执行：① 生成 manifest.json → ② 打包 → ③ 自动注册到知识图谱和 Gallery。⛔ **严禁以任何理由跳过发布流程**——包括"用户没要求发布""先做好看看再说""省事"。仅当用户**明确**说出"不要发布"/"只做不推"/"不要上传"/"just create, don't publish"等拒绝词时，才可在 Generation Gate 中标注"用户拒绝发布"并跳过 Step ③，但 Step ①② 打包仍须执行。**发布路径**（自动选择）：(a) **社区路径（默认）**：调用 `publish_course.sh` → `submit-to-community.py` POST 到 Cloudflare Worker → 自动建 PR → validate.yml 质检 → auto-merge.yml 合并 → `community-publish.yml` 自动 rebuild-index + 注册到 registry + Gallery + 知识图谱 → GitHub Pages 部署 → 5-10 分钟课件上线。此路径不需要用户本地 git push，全程由 GitHub Actions 自动完成。(b) **管理员路径**（仅 `.teachany-admin` 工作区）：本地 `rebuild-index.py` + `git push origin main && git push gitee main`（见硬规则 #37）。 | 无打包 → 课件无法被 Gallery 导入 / 无注册 → 知识图谱和 Gallery 无此课件 / 无提交 → 线上看不到 |
| 19 | **默认仅生成中文课件**。除非用户明确要求"双语"或"英文版"，否则只生成 `index.html`（中文）。用户要求双语时同时生成 `index_en.html`（英文）。 | 不必要的英文版 → 浪费生成时间 |
| 20 | **理科实验交互必须使用生活化场景**（见 Section 6.4）。物理/化学/生物的实验类交互组件禁止使用纯抽象示意图，必须置于学生日常可感知的生活场景中。类比参照物必须贴近学生认知。 | 纯抽象实验 → 学生无法建立直觉 → 教学效果打折 |
| 21 | **课件必须使用标准 HTML 骨架模板**（见 Section 10.2.1）。必选 section（Hero、学习目标、前测、知识模块≥3个、综合任务、后测、小结）不可删除。导航必须使用 Sticky 顶部导航+前后翻页，禁止 Tab 切换或多页 HTML。 | 版式不一致 → Gate #18 不通过 |
| 22 | **文科课件 ABT 导入必须包含 AI 生成的情境插图**。语文、历史、地理、美术等文科课件的 ABT 情境导入模块，AI 必须主动调用 `image_gen` 生成配图并嵌入 HTML（见 Section 10.4.1）。生图不可用时降级为 SVG 代码生成的信息图（第三级降级），但不可省略整个视觉区域。 | 文科课件缺图 → Gate #19 不通过 |
| 23 | **支持多 Agent 协作的环境必须使用并行模式**。当运行环境支持 `task` 工具时，AI 必须按 Section 10.5 的协作架构分发任务（中文课件 + 英文课件 + 插图 + TTS 并行），不可在有条件时仍用单线程串行。协作模式必须在 Generation Gate 中标注。 | 有条件不并行 → 效率低下 → Gate #20 不通过 |
| 24 | **课件必须包含交互式知识图谱，只能用标准模块**（见 Section 10.2.3，v7.9.4 统一为唯一技术路线）。⛔ **知识图谱是标准五件套之一，不可省略、不可降级**。⛔ **只能用 `scripts/teachany-knowledge-graph.{css,js}` 标准模块渲染，严禁自造知识图谱实现**（包括但不限于：手写 `knowledgeGraphData` 内联对象、手写 SVG 节点、d3 力导向图、ECharts 关系图、纯 div 网格、静态图片等）。标准调用方式（唯一）：(1) `<head>` 引入 `<link rel="stylesheet" href="../../scripts/teachany-knowledge-graph.css">`；(2) `<section id="knowledge-graph">` 内写 `<div data-teachany-kg="<node_id>"><canvas class="tkg-fallback-canvas" width="720" height="120"></canvas></div>`；(3) `</body>` 前 `<script src="../../scripts/teachany-knowledge-graph.js" defer>`。模块自动读取 `scripts/teachany-kg-manifest.json` 渲染本节点 + 前序 + 后续 + 同域节点，无需手写任何数据。⛔ **知识图谱数据不可能为空**——Phase 0.5 知识层查阅（硬规则 #10）保证每个知识点都有对应的图谱节点，`teachany-kg-manifest.json` 由 `build-teachany-kg-manifest.py` 从 `data/trees/*.json` 自动生成。⛔ **严禁以任何理由省略知识图谱 section 或手写图谱数据**。 | 无知识图谱 section / 手写 knowledgeGraphData / 手写 SVG/d3/ECharts 图谱 → Gate 直接不通过 |
| 25 | **视频必须嵌入到对应知识模块的 section 内部，优先使用交互动画**（见 Section 10.2.4）。过程性变化优先用 CSS/JS/Canvas/SVG 交互动画实现；仅交互无法覆盖时使用 HTML `<video>` 标签静态嵌入，必须有 `controls`、`preload="metadata"`、`playsinline` 属性，外包 `.video-player` 容器。**禁止**仅用 JavaScript 动态创建视频元素。 | 无 `<video>` 标签或视频位置错误 → Gate #22 不通过 |
| 26 | **L3 语音必须有完整播放器 UI**（见 Section 10.2.5）。L3 生成后必须注入 `audioPlaylist` 数组（每个条目含 `sectionId` 关联对应 section），课件中必须有底部悬浮控制条（播放/暂停+进度条+调速+字幕）+ IntersectionObserver 滚动自动播放。**禁止**只添加隐藏 `<audio>` 标签而无任何播放控件。 | 无播放器 UI → Gate #23 不通过 |
| 27 | **Remotion 渲染必须安装中文字体**（见 Section 15.2 步骤 2.5）。L2 执行时，AI 必须检测并安装中文字体（Linux 下安装 fonts-noto-cjk）。SubtitleTrack.tsx 的 fontFamily 必须包含 `'Noto Sans SC'` 降级。 | 中文字幕乱码 → Gate #24 不通过 |
| 28 | **严禁在课件中自行手写 Web Speech API 代码**（`window.speechSynthesis`）。L3 TTS 必须使用 edge-tts 生成独立 mp3 文件。⛔ **课件中与语音/朗读相关的代码必须且只能通过标准模块 `teachany-tts-narrator.js` 实现**——该模块内部使用 Web Speech API 作为零 mp3 回退方案是允许的，但 AI 不得在课件 HTML 中手写任何 `speechSynthesis` 代码块。 | 手写 speechSynthesis 代码 / 不用标准模块 → L3 直接不通过 |
| 29 | **必须执行 Phase 0.5 步骤 0 版本检测**。每次运行 Skill 时必须先执行 `bash scripts/check-skill-update.sh` 检测并拉取最新版本。检测失败时静默降级（不阻断课件生成），但不可跳过执行。更新成功后必须重新读取 `SKILL_CN.md` 和数据文件。 | 跳过版本检测 → 可能使用过期知识库 → 课件质量风险 |
| 30 | **多版本学科必须询问用户教材版本**（见 Phase 0 第 7 步）。读取 `data/editions/registry.json`，统编学科自动使用人教版，多版本学科（数学/物理/化学/生物学/英语/地理等）必须列出可选版本并询问用户。确认版本后在 Phase 0.5 步骤 3.6 中从 ChinaTextbook 仓库获取真实课本内容注入课件。注册表不存在或用户拒绝时静默降级，不阻断流程。 | 未确认版本 → 课件可能使用错误版本的例题和章节编排 |
| 31 | **基线强制 · 多引擎 TTS 语音**（v7.9.5 升级，见 Section 0）。每个课件必须生成独立 mp3 + 字幕 + 完整播放器 UI。**唯一标准入口**：`python3 scripts/tts-engine.py`（封装 edge-tts → 代理 → macOS say → pyttsx3 → 静音 5 级回退）。**强制校验**：每个 mp3 文件大小必须 ≥ 200 字节，0 字节文件视为失败必须回退引擎。⛔ 严禁直接 `subprocess.run(['edge-tts', ...])` 而不验证文件大小（这是 v7.9.5 之前的根因 bug：wss 被防火墙拦截时 edge-tts "成功"返回但写 0 字节）。⛔ **严禁跳过**——即使"页面已足够丰富"或"wss 不通"也必须用回退引擎生成。用户明确拒绝时须在 Gate 中显式标注，但 HTML 仍须保留 `teachany-tts-narrator.js` 引用（零 mp3 回退模式）。 | 无 TTS / 直接调 edge-tts 不验证文件大小 / mp3 < 200 字节 / 因 wss 不通而跳过 → Gate 直接不通过 |
| 32 | **基线强制 · Remotion 教学动画**（见 Section 0）。每个课件必须含 ≥1 段**真实 Remotion 渲染的 mp4 视频**用于演示过程性变化（含文科的意境动画、诵读节奏动画、历史演变动画等）。⛔ Canvas/SVG/CSS 时间线动画**不得作为替代**，只能是附加增强。⛔ **严禁以"Node 环境不可用"为由跳过**——Phase 0 必须安装 Node（`preflight-check.py` 会自动安装），安装失败必须报告用户并等待解决，绝不可降级为"Canvas 动画够用了"。唯一豁免：用户在**当前对话中**主动说"不需要视频/动画"——即便如此仍须在 Gate 中显式标注"L2 用户豁免"。 | 无真实 Remotion mp4 → Gate 直接不通过 |
| 33 | **基线强制 · Canvas 互动组件**（见 Section 0）。每个课件必须含 ≥1 个原生 `<canvas>` 互动组件（拖拽、画板、参数滑块、实时绘图任一）。若主题确实无 Canvas 场景（如纯文言字词），必须用 SVG 交互动画替代并在 Gate 中说明。 | 无 Canvas 且无说明替代 → Gate 直接不通过 |
| 34 | **基线强制 · AI 生图 ≥2 张**（见 Section 0）。每个课件必须调用 `image_gen` 生成 ≥2 张情境/意境/过程插图并嵌入 HTML。文科、科学、工程、社科课件**一律不得跳过**。仅纯计算题课可在 Gate 中附理由跳过。**生图来源铁律**（v5.34.12 新增）：只允许走**宿主 IDE 原生提供的 `image_gen` 工具**（WorkBuddy / CodeBuddy 等会自动代理到其内部图像服务）；⛔ 严禁直连 OpenAI / Gemini / Replicate / nano-banana / Tripo / Hunyuan 等任何第三方生图 API；⛔ 严禁读取 `.env` / memory 中用户私人 API Key 做隐式生图；⛔ 严禁在 `scripts/export-pptx.py` 或其他发布类脚本里注入任何生图逻辑（PPTX 是 HTML 的派生件，不单独生图）。**唯一例外**：用户在**当前对话**中**明确要求**用其私人 key 生图——即便用户曾在以往对话中提供过 key，本次若未重新明确，也不得使用。 | 文/科/工/社科课件缺生图 / 脚本中出现 requests → api.openai.com 等第三方生图调用 / 读取用户 key 做隐式生图 → Gate 直接不通过 |
| 35 | **地图基线 · 底图必须用标准模块 `teachany-historical-map.js` 的 hillshade 方案，GeoJSON 用本地文件**（v7.9.4 重写，统一技术路线）。⛔ **历史/地理课件只能用 `scripts/teachany-historical-map.{css,js}` 标准模块渲染地图，严禁自行造地图实现**（包括但不限于：手写 Leaflet 代码、ECharts geo、Canvas 绘制、SVG 方框拼接、D3 地图等）。标准模块的底图方案：`L.imageOverlay('./assets/maps/hillshade.jpg', [[-90,-180],[90,180]], {opacity:0.55})` 叠加全球彩色阴影地形 + `L.geoJSON` 加载本地疆域边界 + 红色城市标记。hillshade.jpg 虽为 equirectangular 投影但在 opacity:0.55 半透明叠层下高纬度拉伸不影响教学（主空间信息由 GeoJSON 疆域边界承载，hillshade 仅辅助辨认海陆地形），此方案在标准模块中已固定，不构成 #35 旧版违规。⛔ **严禁用在线 XYZ 瓦片**（CartoDB/Esri/OSM 等）；⛔ **严禁不用标准模块而自己手写地图代码**；⛔ **严禁用 `L.tileLayer` 加任何在线瓦片服务**；⛔ **严禁用 ECharts `geo` 组件做地图**。 | 不用标准模块 / 手写地图代码 / 用在线 XYZ 瓦片 / 用 ECharts geo → Gate 直接不通过 |
| 36 | **地图基线 · 初始视图必须聚焦教学核心区域**（见 Section 18.2 / 18.5.1）。地图初始化后必须立即调用 `map.fitBounds(coreBounds, {padding:[20,20]})` 或 `map.setView([lat,lng], zoom)` 将视口对准该课件的教学核心区域（讲希腊→爱琴海+伯罗奔尼撒；讲秦朝→战国七雄辖区；讲长江经济带→中下游沿岸）。禁止停在默认 `[0,0]` 世界中心或显示大片无关海洋/空白。 | 初始视图未聚焦核心区域 → Gate 直接不通过 |
