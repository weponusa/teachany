# AI Multimodal（精简版）

AI 多模态只在用户明确需要或学科场景确实有价值时启用。不要让多模态能力压过教学主线。

## 使用场景

- 图像理解：学生上传作业、实验照片、地图/图表截图。
- 口语/朗读：语文诵读、英语跟读。
- PBL：学生提交作品，AI 做诊断式反馈。

## 设计原则

1. 先问学生目标，再分析输入。
2. 反馈要诊断知识缺口，不只给答案。
3. 输出要给下一步行动：重试、修正、查看哪个模块。
4. 不上传敏感个人信息；不保存不必要的学生隐私数据。

## 页面结构

```html
<section id="multimodal" class="ta-section">
  <h2>上传你的尝试</h2>
  <input type="file" accept="image/*,audio/*">
  <button>让 AI 帮我诊断</button>
  <div class="feedback-panel"></div>
</section>
```

## 降级

如果当前环境没有多模态 API，保留人工输入框：让学生描述自己的图/声音/步骤，AI 学伴仍可基于文字诊断。
