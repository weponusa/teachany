# TeachAny · Sparse Checkout Preset · standard ⭐ 推荐
# 制作器内核 + 历史地图 + 现代政区，约 60-65MB（工作目录）
# 适用场景：所有课件制作（含历史/政治课件的标准地图模块）
#
# ⚠️ 本文件仅使用 cone 模式兼容语法（纯目录/子目录路径）
#   · 不使用 ! 否定（cone 模式不支持）
#   · 不使用 * 通配符（cone 模式不支持）
#   · 未列出的目录自动排除
#
# 用法（cone 模式）：
#   git sparse-checkout init --cone
#   git sparse-checkout set skill/ scripts/ data/trees/ data/knowledge-points/ data/geography/ data/editions/ data/textbook-supplements/ assets/maps/chrono-cn/ assets/maps/chrono-world/ assets/maps/political/ assets/maps/physical/hillshade/ references/ docs/ .sparse-checkout-presets/
#
# 地理课件需要自然地理底图时，执行：
#   git sparse-checkout add assets/maps/physical/
#   # 追加 coastline(21MB) + rivers(16MB) + lakes(7.7MB) + terrain-tiles(11MB)

# ── 制作器核心 ──
skill/
scripts/
references/
docs/

# ── 知识树与知识点（不含 data/excerpts/ 课标摘录 26MB）──
data/trees/
data/knowledge-points/
data/geography/
data/editions/
data/textbook-supplements/

# ── 地图资产（历史 + 政区 + hillshade 底图） ──
assets/maps/chrono-cn/
assets/maps/chrono-world/
assets/maps/political/
assets/maps/physical/hillshade/

# ── sparse checkout 预设文件本身 ──
.sparse-checkout-presets/

# ── 以下目录按需追加 ──
# 地理课件自然地理底图（+58MB）：git sparse-checkout add assets/maps/physical/
# 课标原文摘录（+26MB）：git sparse-checkout add data/excerpts/
# 全部成品课件（+700MB）：git sparse-checkout disable
