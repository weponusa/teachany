1什么是简谐运动 (What is SHM?)

📖 定义

简谐运动 (Simple Harmonic Motion, SHM) 是最基本、最重要的振动形式。当物体偏离平衡位置时，所受的回复力与位移成正比，且方向指向平衡位置：

F = −kx
k: 劲度系数 (N/m) | x: 相对平衡位置的位移 (m)
⚡ 这个"负号"至关重要——它表示回复力总是指向平衡位置，与位移方向相反。这正是简谐运动的本质特征！

SHM 之所以"简单"，是因为它的位移-时间关系可以精确地用正弦或余弦函数描述。这种规律性使它成为理解所有复杂振动的基础。

🔑 核心物理量

振幅 Amplitude (A)
最大位移
单位: m
周期 Period (T)
完成一次全振动的时间
单位: s
频率 Frequency (f)
每秒完成的振动次数
f = 1/T, 单位: Hz
角频率 (ω)
ω = 2πf = 2π/T
单位: rad/s
相位 Phase (φ)
决定初始状态
单位: rad
劲度系数 k
弹簧"硬度"
单位: N/m
2弹簧振子 — PhET 互动仿真

🔧 弹簧振子公式

弹簧振子是理想 SHM 的典型实例。胡克定律与惯性结合，产生简谐运动：

T = 2π√(m/k)
周期 — 注意：T 与振幅 A 无关（等时性）！
ω = √(k/m)
角频率 — 由系统固有性质决定
⚠️ T = 2π√(m/k) 意味着：质量越大，周期越大（越慢）；弹簧越硬（k 越大），周期越小（越快）。
这个"与振幅无关"的性质叫做等时性，是伽利略在比萨大教堂发现的！
连接方式等效劲度系数周期变化
并联k_eq = k₁ + k₂周期变小（变快）
串联1/k_eq = 1/k₁ + 1/k₂周期变大（变慢）

3数学描述 (Mathematical Description)

📐 位移、速度、加速度公式

以余弦函数为例（正弦函数只是相位差 π/2）：

x(t) = A cos(ωt + φ)
位移 — 时间关系
v(t) = −Aω sin(ωt + φ)
速度 = 位移对时间的一阶导数
a(t) = −Aω² cos(ωt + φ) = −ω²x
加速度 = 二阶导数，a ∝ −x 正是 SHM 的定义！
⚠️ 重要规律：速度最大值 v_max = Aω（在平衡位置，x = 0）
加速度最大值 a_max = Aω²（在最大位移处，x = ±A）

📊 三大关键结论

结论表达式说明
回复力与位移正比反向F = −kx 或 a = −ω²x这是 SHM 的判定条件
速度与位移相位差 π/2x 最小时 v 最大能量转换的体现
加速度与位移反相a = −ω²x相位差 π，加速度总指向平衡位置
周期与振幅无关！T = 2π√(m/k) 或 2π√(L/g)等时性，伽利略的发现

4能量 (Energy in SHM)

⚡ 动能、势能与机械能守恒

在理想 SHM 中（无摩擦、无阻力），机械能守恒！

KE = ½mv² = ½mA²ω²sin²(ωt+φ)
动能 — 随时间周期性变化
PE = ½kx² = ½kA²cos²(ωt+φ)
弹性势能 — 也随时间周期性变化
E_total = ½kA² = ½mA²ω² = 常数！
机械能守恒 — SHM 最重要的能量特征
💡 能量视角的威力：无论运动到哪个位置，总有 E = KE + PE = ½kA²。
利用这一点可以直接求任意位置的速度：v = ±ω√(A²−x²)

5单摆 — PhET 互动仿真

⏳ 单摆公式（小角度近似）

当摆角 θ 很小时（θ < 15°），单摆的运动近似为简谐运动：

T = 2π · √(L/g)
周期只与摆长 L 和重力加速度 g 有关，与振幅和质量无关！
⚠️ 前提条件：小角度近似
只有当 sin θ ≈ θ（θ 用弧度）时，单摆才近似做 SHM。
当 θ = 15° 时误差约 1.7%；θ = 30° 时误差约 9.7%——已经相当显著！
🔬 PhET 仿真 · Pendulum Lab（单摆实验室） PhET

💡 操作建议：① 开启"周期计时器"测 T；② 分别改变摆长、质量、初始角度，验证哪些因素影响 T；③ 切换星球重力，观察 g 对周期的影响。

🔬 大角度单摆 — 非线性效应（拓展内容） ▼

当摆角较大时，单摆不再满足简谐运动条件，其运动方程变为：

d²θ/dt² = −(g/L)sinθ
精确方程（无法用初等函数解析求解）
  • 周期随振幅增大而增大（不再等时）
  • 运动变为非线性，可能出现混沌
  • 可用椭圆积分精确求周期：T = 4√(L/g) · K(sin(θ₀/2))
💡 这正是物理学的魅力——简单系统在大参数下会产生复杂行为！
